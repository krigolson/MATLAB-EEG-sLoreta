# Notices

This toolbox includes a small number of copied template assets so the examples
and plotting functions can run without requiring a full EEGLAB or FieldTrip
installation on the MATLAB path.

## FieldTrip / DIPFIT Template Assets

The following files are derived from template assets distributed with
FieldTrip and/or EEGLAB DIPFIT:

- `templates/dipfit/standard_BEM/standard_vol.mat`
- `templates/dipfit/standard_BEM/standard_mri.mat`
- `templates/dipfit/standard_BEM/standard_seg.mat`
- `templates/dipfit/standard_BEM/elec/standard_1005.elc`

FieldTrip template documentation:

- https://www.fieldtriptoolbox.org/template/
- https://www.fieldtriptoolbox.org/template/headmodel/
- https://www.fieldtriptoolbox.org/template/anatomy/

EEGLAB DIPFIT documentation:

- https://eeglab.org/tutorials/09_source/DIPFIT.html

The FieldTrip GPL license text is included in:

- `third_party_licenses/FIELDTRIP_COPYING_GPLv3.txt`

## Brainstorm Cortex Template

The cortex/atlas template used for surface plotting and region summaries is:

- `templates/cortex/brainstorm_icbm152_cortex_pial_low.mat`

This file is included only as a lightweight plotting/atlas template for this
toolbox.
